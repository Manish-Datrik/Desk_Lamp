# Adjustable Desk Lamp

A 3D CAD project of an adjustable desk lamp designed using **Autodesk Fusion 360**. The main idea was to create a lamp that can be adjusted into different positions, with a stable base, movable arms and a tilting lamp head.

Printables:- https://www.printables.com/model/1925667-adjustable_desk_lamp
## project overview

This project focuses on designing a practical desk lamp with adjustable parts. The lamp has a circular base, two connected arms and a movable lamp head. The joints allow the lamp to be positioned according to the user's needs.

I designed each part separately and then brought everything together to form the complete assembly. I also added cable guides, clips, joint covers and rubber pads to improve the overall design.

## software used

- **Autodesk Fusion 360** – 3D modelling and assembly.

## key features

- Circular base for stability.
- Two adjustable arms.
- Movable elbow joint.
- Tilting lamp head.
- Adjustment knobs at the joints.
- Cable channels and clips to keep the cable organised.
- Rubber pads under the base for better grip.
- Joint covers for a neat finish.
- Separate front cover for the lamp housing.

## cable management

To keep the design organised, I added small channels and clips along both arms to guide the cable. A cable guide was also added near the base, along with a cable anchor at the back of the lamp housing.

The cable itself and electrical components are not included in the current CAD model.

## assembly and movement

The different parts are connected using joints in Fusion 360. These allow the base connection, elbow and lamp head to move.

I also checked the assembly for overlapping parts and adjusted the movement limits where needed.

## project outcome

The project resulted in a complete 3D model of an adjustable desk lamp, including its base, arms, joints, lamp housing and finishing details.

Working on this project helped me understand 3D modelling, part design, assembly connections and movement in Autodesk Fusion 360. It also gave me practical experience in building a product design step by step.
